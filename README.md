# الفن القبطي — ملخص تفاعلي (COTA)

موقع مذاكرة تفاعلي لمادة **الفن القبطي** (ماجستير تاريخ الكنيسة — الكلية الإكليريكية بالإسكندرية)، ص ٣–٥٣ (Quiz 1).

- ١٢ محور + خط زمني + خريطة + شخصيات + **المعجم المساعد** (آلهة وأساطير ومصطلحات) + فلاش كاردز + بنك أسئلة (اختيار · صح وغلط · أكمل) + زاوية نقدية.
- صفحة واحدة `index.html` مستقلة (الصور مدمجة جواها) — تشتغل أوفلاين.

## التعديل
- المصدر في `src/template.html` والصور في `src/imgs.json`.
- بعد أي تعديل: `python3 src/build.py` ← بيطلع `index.html` في الجذر.
- النشر: Vercel بينشر `index.html` تلقائيًا مع كل push على `main`.
